My name is **Nikita Konkin**. This site is a public showcase of my projects, technical writing, and working updates.

Here I publish:

- architecture and algorithm breakdowns;
- notes on backend development, data processing, and document automation;
- project updates in a format that works both as a portfolio and as a readable engineering blog.

The main goal of the site is not to store articles as an archive, but to show:

- **what was actually built**;
- **why it was built that way**;
- **which engineering decisions were used**;
- **where to see the code or the live demo**.

If I extend the site further, the next logical step is to add dedicated pages for each project, a favicon, preview images, and GitHub Actions for automatic build checks.
